# Animus AI Studio — site institucional

Código do site [animusai.com.br](https://www.animusai.com.br).

A Animus constrói sistemas sob medida com IA para pequenos negócios. O site explica isso em poucos segundos e leva o visitante a uma conversa.

## Como foi feito

- HTML, CSS e JavaScript puros, sem framework e sem etapa de build.
- Mapa 3D no topo da página em Three.js, com tema claro e escuro.
- Pensado primeiro para o celular.
- Casos reais no formato "antes e depois", começando pela dor do cliente.
- SEO técnico: `sitemap.xml`, `robots.txt`, dados estruturados e página 404 própria.
- Página de privacidade (LGPD) ligada ao formulário.
- Publicado na Vercel, com DNS na Cloudflare.

## Estrutura

| Arquivo | O que é |
|---|---|
| `index.html` | Página principal |
| `privacidade.html` | Política de privacidade |
| `404.html` | Página de erro |
| `assets/` | Imagens, vídeos e scripts |
| `PRODUCT.md`, `DESIGN.md` | Decisões de produto e de design |
